Linux Directories
What I Learned
Linux organises its files and resources into a hierarchical directory structure. Unlike Windows, where drives such as C: are commonly used as the starting point, Linux has a single directory structure that begins at the root directory, represented by /.
I can view the directories directly under the root directory by running:
ls /

The / at the beginning represents the root of the entire Linux filesystem. Everything else in the filesystem exists somewhere underneath this directory.

Some of the important directories I learned about are:
/bin — Essential Executable Programs
The /bin directory contains essential executable programs and commands that are needed for the system to perform basic operations.
These are programs that users and the system can execute from the command line. Commands such as ls, cp, mv, and other fundamental utilities are traditionally associated with this directory.
On modern RHEL systems, /bin may be implemented as a symbolic link to /usr/bin, but it is still important to understand /bin as the location traditionally associated with essential user commands.

/home — User Home Directories
The /home directory contains the personal home directories of normal users.
For example:
/home/alice
/home/bob

Each user typically has their own directory where they can store personal files, documents, configuration files, and other user-specific data.
This means that /home is generally where normal users' personal working environments are located.

/root — Root User's Home Directory
/root is the home directory of the root user, also known as the superuser.

•	/ is the root of the entire filesystem.
•	/root is a specific directory belonging to the root user.

The root user has very high-level privileges and can perform administrative operations that normal users generally cannot. Access to /root is therefore normally restricted to the root user or users with appropriate administrative privileges.

/tmp — Temporary Files
The /tmp directory is used for temporary files created by applications and users.
Files placed here are generally not intended to be permanent. Programs may use /tmp when they need somewhere to temporarily store data while performing an operation.
Because the files are temporary, they should not be treated as a reliable place to permanently store important information.

/mnt — Mount Points
The /mnt directory is traditionally used as a location where filesystems can be temporarily mounted.
Mounting means making another filesystem or storage device accessible through a directory in the Linux filesystem hierarchy.
For example, an administrator could mount another filesystem at:
/mnt/data
After it is mounted, the contents of that filesystem can be accessed through /mnt/data.

/run — Runtime Data
The /run directory contains runtime data created by the system and running processes.
This can include information such as process IDs, sockets, and other temporary system information that is needed while the system is running.
Unlike /tmp, /run is specifically intended for data related to the current running system and its services.
The contents of /run are generally temporary and are recreated when the system starts.

/var — Variable Data
The /var directory contains data that is expected to change frequently while the system is running.
The name comes from "variable," because the contents of this directory are not expected to remain constant.
Examples include:
•	System and application logs
•	Spool files
•	Caches
•	Databases and other application data
•	Other information that changes as services and applications operate
For example, logs can be stored under:
/var/log

This makes /var particularly important when troubleshooting a Linux system because system and application activity is often recorded in its log files.
Important Distinction: / vs /root
One of the most important things I took from this section is that root can refer to two different things depending on the context.
/ is the root directory. It is the starting point of the entire Linux filesystem hierarchy.
/root is the home directory of the root user.
The root user is the Linux superuser, meaning it has extensive administrative privileges over the system. This is why access to /root and many other system directories is restricted.
Overall Understanding
The Linux directory structure is organised according to the purpose of the data stored in each location. Rather than putting files anywhere randomly, Linux follows a standard filesystem hierarchy where directories have specific roles.
Understanding this structure is important because it allows me to know where system files, user files, temporary files, runtime information, executable programs, and logs are normally located. This will make navigating and administering a Linux system much easier as I continue learning RHEL.
