What I Learned:
This lesson covered how to manage software and updates on a Red Hat system. The main areas were system registration, software management with DNF, Red Hat errata and security advisories, and applying updates safely.
The overall workflow is:
Register → Find packages → Install/update → Check security → Reboot if needed

Registering a Red Hat System
A Red Hat system can be registered with the Red Hat Content Delivery Network (CDN). Registration gives the system access to Red Hat software, packages, updates, and repositories.
The subscription-manager command is used to manage Red Hat system registration and subscriptions.

To check whether a system is registered:
subscription-manager identity

To register a system:
subscription-manager register

To force registration when appropriate:
subscription-manager register --force

Red Hat Satellite
The lesson also introduced Red Hat Satellite.
Satellite is useful for managing software, updates, and content across multiple Red Hat systems. Instead of every server connecting directly to the Red Hat CDN, Satellite can download and store content and make it available to other servers.
This is particularly useful in larger environments or environments where servers do not have direct internet access.

The basic structure is:
Servers → Satellite → Red Hat CDN

Managing Software with DNF
DNF is the package manager used on RHEL systems. It can be used to search for, install, update, and manage software packages.

To search for a package:
dnf search <package>
To install a package:
dnf install <package>

DNF also performs automatic dependency resolution. When a package requires other packages to work correctly, DNF identifies and installs the required dependencies.
The -y option can automatically confirm prompts:
dnf install -y <package>
This should be used carefully because it removes the opportunity to review and confirm the proposed changes.

Red Hat Errata
Red Hat publishes errata when software needs updates, bug fixes, enhancements, or security fixes.

The three main types are:
Type	Meaning	Purpose
RHBA	Red Hat Bug Fix Advisory	Fixes bugs
RHEA	Red Hat Enhancement Advisory	Provides enhancements
RHSA	Red Hat Security Advisory	Addresses security vulnerabilities

A useful way to remember them is:
RHBA → Bug
RHEA → Enhancement
RHSA → Security

CVEs and CVSS
Security advisories can reference CVEs.
CVE stands for Common Vulnerabilities and Exposures. A CVE provides a standard identifier for a known security vulnerability.
CVSS stands for Common Vulnerability Scoring System and is used to indicate the severity of a vulnerability.

The distinction is:
CVE  → Identifies the vulnerability
CVSS → Indicates its severity
A single security advisory can address multiple CVEs.

Finding Available Errata
To list available update information and advisories:
dnf updateinfo list

To view detailed information about a specific advisory:
dnf updateinfo info <ADVISORY-ID>
This can provide information about the advisory, affected packages, related CVEs, and the issue being addressed.

Updating the System
To update installed packages:
dnf update
This applies the available package updates to the system.
Security updates can be prioritised separately:
dnf update --security
Specific security severities can also be targeted:
dnf update --sec-severity=critical
This allows administrators to prioritise security fixes based on their severity instead of applying every available update at once.
Checking Whether a Reboot Is Required
After applying updates, some changes may require a system reboot before they become fully active.
To check whether a reboot is required:
dnf needs-restarting -r
If a reboot is required, the system can be restarted with:
reboot
This is particularly relevant when updates affect components such as the running kernel.

Overall Understanding
This lesson showed me that managing a Red Hat system involves more than simply installing software. Software needs to be obtained from trusted repositories, kept up to date, and monitored for security vulnerabilities.
The main commands and concepts I learned were:
•	subscription-manager — manages Red Hat registration and subscriptions.
•	Satellite — centrally manages Red Hat content for multiple systems.
•	dnf — manages software packages and updates.
•	Errata — Red Hat advisories for bugs, enhancements, and security issues.
•	RHSA — security advisories.
•	CVE — identifies a known vulnerability.
•	CVSS — indicates vulnerability severity.
•	dnf update --security — applies security updates.
•	dnf needs-restarting -r — checks whether a reboot is required.
The key takeaway is that software management and system maintenance are also security responsibilities. Keeping packages updated and addressing important security vulnerabilities helps maintain a secure and reliable RHEL system.
