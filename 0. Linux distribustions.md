What I learned:

I gained an introduction to Red Hat Enterprise Linux (RHEL) and the broader Linux ecosystem Red Hat utilizes. Red Hat products rely on the Linux kernel the core component of an operating system that manages hardware, memory, processes, and system resources.

I also gained an understanding of how Fedora, CentOS Stream, and RHEL differ from one another. Fedora functions as a community-driven Linux distribution focused on introducing and testing emerging technologies, serving as a proving ground for newer ideas. CentOS Stream sits between Fedora and RHEL, offering a continuously updated preview of upcoming minor RHEL releases so developers can work with features before they reach full stability. RHEL itself represents Red Hat's enterprise-grade platform, prioritizing stability, security, long-term support, and reliability for organizations managing critical production workloads.

Ultimately, these three distributions form a clear pipeline: Fedora tests new technologies, CentOS Stream previews upcoming enterprise features, and RHEL delivers a stable, fully supported environment for enterprise operations.
