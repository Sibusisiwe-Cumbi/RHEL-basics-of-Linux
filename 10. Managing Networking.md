What I Learned:
This lesson introduced NetworkManager, which is used to manage networking on RHEL systems. It also covered nmcli, nmtui, and commands used to check and verify network configuration.

NetworkManager
NetworkManager manages Linux networking.

Network devices appear as network interfaces, for example:
•	enp7s0
•	eth0
•	wlp2s0

NetworkManager uses connection profiles to store network settings such as:
•	IP address
•	Gateway
•	DNS servers

An interface can have multiple profiles configured, but only one profile can be active on an interface at a time.

nmcli
nmcli is the command-line tool for managing NetworkManager connections.

nmcli con show
Shows all network profiles.
nmcli con show <profile>
Shows the configuration of a specific profile.
nmcli con del <profile>
Deletes a network profile.

nmcli can also be used to create and configure network profiles, including static IP configurations.

nmtui
nmtui provides a text-based interface for managing network profiles.

nmtui
It can be used to create, edit, and delete network profiles through a menu. This provides an easier alternative to entering longer nmcli commands.

Checking Network Configuration
The ip command can be used to check network interfaces and addresses.
ip address show
or:
ip a s
Shows network interfaces and their IP addresses.

To check routing information:
ip route show
or:
ip r s
Shows routes and the default gateway.

DNS configuration can be checked with:
cat /etc/resolv.conf
This shows the DNS servers being used for name resolution.

Static Network Configuration
A static network configuration can contain:
•	Interface: enp7s0
•	IP address: 192.168.1.114/24
•	Gateway: 192.168.1.1
•	DNS: 192.168.1.1, 1.1.1.1

Key Takeaways
•	nmcli → manage networking from the command line.
•	nmtui → manage networking through a text-based menu.
•	ip address → check interfaces and IP addresses.
•	ip route → check routes and the gateway.
•	/etc/resolv.conf → check DNS configuration.

Overall Understanding
NetworkManager provides a central way to configure and manage network connections on RHEL. nmcli and nmtui are used to configure networking, while ip commands and /etc/resolv.conf help verify the current configuration.
A useful system administration habit is:
Configure → Verify
