The main lesson from this video was that I do not need to memorise every shell command. Instead, I can use the documentation available within Linux to find the information I need.

One of the most useful tools for this is the man command, which provides access to manual pages for commands.

For example:
man ls

This opens the manual page for ls, where I can find information about what the command does, the options it supports, and how those options can be used.

I also learned that the man command itself has a manual page. This means that if I want to understand how the man command works, I can simply run:

man man

This reinforced an important principle for working with the Linux command line: I do not need to rely on memorisation. I can use the system's documentation to discover how commands work and determine which options are appropriate for what I am trying to accomplish.

Instead of trying to remember every command and every available option, I can become comfortable with finding, reading, and applying the relevant documentation.
