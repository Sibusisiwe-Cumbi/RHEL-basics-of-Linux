What I Learned:
This video covered the basic commands used for managing files and directories from the Linux command line. Most of the commands were already familiar to me, so this lesson was a useful revision of fundamental Linux file-management operations and helped reinforce commands that I have used before.

Listing Files and Directories
The ls command is used to list the contents of a directory. I was already familiar with using ls, as well as some of its common options:
ls -l
ls -lh
The -l option displays the contents in a long listing format, providing additional information about each file, such as its permissions, ownership, size, and modification time.
The -h option makes file sizes human-readable, displaying sizes using units such as KB, MB, or GB instead of only showing the raw number of bytes.
One option I was not previously familiar with was:
ls -lha
This combines the -l, -h, and -a options. The -a option includes hidden files and directories in the listing. Therefore, ls -lha allows me to see a detailed listing of all files, including hidden files, with their sizes displayed in a human-readable format.

Creating Directories
The mkdir command is used to create directories. I was already familiar with creating a directory by providing its name:
mkdir directory_name
However, I learned about the -p option:
mkdir -p parent/child/grandchild
The -p option allows me to create the required parent directories if they do not already exist. Without -p, the command would fail if the parent directory did not exist.
This was one of the useful additions to my existing knowledge because it allows me to create an entire directory structure with a single command.

Creating Files
The touch command can be used to create an empty file:
touch file.txt
I was already familiar with this command and its use for creating files from the terminal.

Copying Files and Directories
The cp command is used to copy files or directories from one location to another.
For example:
cp file.txt backup.txt
This creates a copy of file.txt called backup.txt.
The command can also be used with options to copy directories and their contents.

Moving and Renaming Files
The mv command is used to move files or directories to another location. It can also be used to rename them.
For example:
mv file.txt documents/
moves the file into the documents directory.
It can also rename a file:
mv old-name.txt new-name.txt
I was already familiar with this command and its two common uses.

Removing Files
The rm command is used to remove files:
rm file.txt
For directories, the -r option can be used to remove a directory and its contents recursively:
rm -r directory_name
The recursive option is important because a directory containing files or other directories cannot normally be removed in the same way as an individual file.

Overall Understanding
This lesson was mainly a revision of basic Linux file-management commands that I had already encountered and used. Commands such as ls, mkdir, touch, cp, mv, and rm were familiar to me, so the lesson helped reinforce my existing knowledge and make sure I understand how these commands are used in a RHEL environment.
The main things that were new to me were the -a option when using ls, particularly the combination:
ls -lha
and the -p option with mkdir:
mkdir -p
These are small additions to my command-line knowledge, but they are useful because they make file and directory management more efficient.
