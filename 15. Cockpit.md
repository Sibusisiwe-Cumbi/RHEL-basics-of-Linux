What I Learned:
Cockpit, also called the RHEL Web Console, is a web-based administration interface for managing RHEL systems through a browser.
It provides a graphical interface for tasks that can also be performed through the terminal, including:
•	System monitoring and logs.
•	Software updates.
•	systemd services.
•	Storage and networking.
•	Firewall configuration.
•	User management.
•	SELinux.
•	Containers and virtual machines.

Cockpit does not replace the underlying Linux administration tools. It provides a visual layer over the existing RHEL system and its standard tools.
Starting Cockpit
Cockpit can be enabled and started with:
sudo systemctl enable --now cockpit.socket
Cockpit uses port 9090. The .socket unit allows systemd to activate Cockpit when a connection is received.

Cockpit vs Terminal
The terminal provides precise control, flexibility, scripting, and automation.
Cockpit provides convenience, visual system information, easier troubleshooting, and a simpler way to perform many administrative tasks.

Overall Understanding
The main idea is:
Cockpit does not replace the terminal — it provides a graphical interface for standard RHEL administration.
